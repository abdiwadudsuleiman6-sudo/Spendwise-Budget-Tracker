# Spendwise Budget Tracker

An updated, interactive web-based **Budget Tracker** built to record and manage personal expenses. This project combines semantic HTML structure, functional inputs, and advanced CSS presentation layouts.

## 🚀 Features Built (Week 2 Upgrades)
* **Structured Data Table:** Implemented an organized table containing column headers (`Name`, `Amount`, `Category`, `Date`) displaying 5 default sample expenses.
* **Upgraded Transaction Form:** Enhanced the input form utilizing an explicit `<form>` element wrapper containing a distinct `<select>` dropdown menu with 5 target budget categories.
* **Interactive Help Details:** Added a toggleable HTML `<details>` and `<summary>` element to provide collapsible instructions for clean workspace navigation.
* **Embedded Multimedia Elements:** Integrated a decorative dashboard logo container along with an educational budgeting YouTube guide (`<iframe>`).

## 🎨 Advanced CSS Layout Techniques Applied
* **Table Formatting:** Implemented `border-collapse: collapse`, cell padding spacing, and an accented solid header row color background.
* **Structural Selectors:** Used the pseudo-class selector `tr:nth-child(even)` to apply alternating light-gray rows for maximum readability.
* **User Experience Interactions:** Configured dynamic dynamic styling triggers using text input `:focus` shadow highlights and standard interactive button row pointer cursors.

## 🛠️ Built Using
* **HTML5** (Semantic elements, tables, forms, multimedia)
* **CSS3** (Advanced combinators, child selectors, pseudo-classes)
